# Build 34 — Forbidden Duel

New mechanics: damage roughly doubled (target ~8–15 attacks depending on composition); 22% critical hits for 1.5x damage; four fusion pairs for 1.5–1.65x damage; independent attack/defense stances per occupied slot, visually rotated in the 5-slot control; upgraded visual feedback for fusion and critical strikes. The existing 999,999,999 HP BUG, reward PDF, and unified duel layout are preserved.

Fusion pairs: ClientFlow+WhatsFlow, StageManager+Texto IA, Suporte Central+Portfolio, Bolso Claro+Academia. A fusion is active when both cards occupy any two slots. The selected card still attacks individually. Defense stance prevents that card from attacking; the stance is reset when replaced. This is an original simplified mechanic, not official Yu-Gi-Oh rules.

To run: npm install; npm run build; npm run dev.
