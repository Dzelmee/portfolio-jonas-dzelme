# Build 40 — Artes de fusão também na arena

As quatro fusões usam agora recortes com transparência derivados das MESMAS ilustrações exclusivas das cartas. Isso substitui os sprites anteriores, que pareciam duas criaturas sobrepostas. Os sprites de fusão também foram ampliados no campo para melhor leitura.

Os guardiões originais, cartas, mecânica de fusão, posições de defesa e ataques permanecem.

A remoção de fundo é automática e pode deixar pequenos artefatos nas bordas. Não são modelos 3D rigados.
