# Build 38 — Artes exclusivas das cartas de fusão

Cada fusão agora tem arte de carta própria (public/fusion-card-art-1.webp a 4.webp), separada do sprite de criatura (src/guardians/fusion-1.png a 4.png). O painel lateral, a carta no tabuleiro 3D e a seleção usam a ilustração exclusiva, enquanto a criatura invocada usa o sprite transparente.

- Rede Suprema: cavaleiro cibernético verde/turquesa
- Sinfonia Neural: mago-condutor roxo
- Fortaleza Digital: guardião azul com escudo
- Titã de Ouro: colosso dourado

A postura de defesa da versão 37 foi preservada: sprite abaixa/inclina e a carta no campo gira 90 graus.

Esta entrega não inclui modelos 3D rigados. A compilação completa no navegador ainda precisa ser validada.
