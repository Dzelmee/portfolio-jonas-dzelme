# Build 39 — Artes dos próprios guardiões nas cartas

As oito cartas principais agora usam ilustrações feitas a partir dos mesmos sprites transparentes que aparecem na arena (`guardian-1.png` até `guardian-8.png`), com cenário, iluminação e moldura de arte exclusivos.

Os arquivos originais de arte dos projetos foram preservados para evitar perda de recursos. As quatro fusões continuam com artes exclusivas e criaturas próprias.

Os dados, regras de fusão, posições de ataque e defesa, combate e cenário foram mantidos.

Para testar: `npm install && npm run build && npm run dev`. A compilação Vite não foi executada neste ambiente.
