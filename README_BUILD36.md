# Build 36 — Fusões reais

Arraste uma carta de uma zona para outra. Quando o par corresponde a uma das quatro receitas, **as duas cartas originais são consumidas**, a zona de origem fica vazia, e a zona de destino recebe um **novo guardião de fusão**, com nome, ATK, DEF, carta e arte de criatura próprios. O novo guardião permanece em campo e pode atacar ou defender. Pares incompatíveis continuam trocando de posição normalmente. O deck original permanece disponível para novas invocações.

Fusões: ClientFlow + WhatsFlow = Rede Suprema; StageManager + Texto. IA = Sinfonia Neural; Suporte Central + Meu Portfólio = Fortaleza Digital; Bolso Claro + Projeto Academia = Titã de Ouro.

As quatro artes de fusão são composições novas feitas a partir dos sprites dos guardiões originais; não são modelos GLB articulados. As animações existentes e a arena foram preservadas.

Verificação: TSX analisado sem erros de sintaxe e ZIP validado. Build Vite e testes em navegador ainda pendentes.
